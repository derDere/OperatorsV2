8-bit Mini PC Assembler

Writes .bin programs for the mini pc simulation. Every instruction is two bytes (opcode, argument), jump targets count instructions. Labels (name:), comments (;), literals as decimal, 0x48 or 'H' / '\n', and the macro PRINT "text" (expands to LDI/OUT per character) are supported.

00 NOP 01 LDI n → ACC = n 02 ADD n → ACC += n 03 SUB n → ACC -= n 04 LDA a → ACC = RAM[a] 05 STA a → RAM[a] = ACC
06 JMP i 07 JZ i (ACC == 0) 08 JNZ i (ACC != 0) 09 OUT → terminal 0A HLT 0B IN → ACC = input
